## 发现的问题（按严重度）
1. 🔴 PlayerController.GameOver()：`StartCoroutine(UIKit.OpenPanelAsync<GameOverPanel>())` 紧接着 `gameObject.SetActive(false)`。SetActive(false) 会停掉该 MonoBehaviour 上所有协程；首次死亡时面板 AB 未缓存 → OpenPanelAsync 会 yield WaitForEndOfFrame → 协程被杀 → 结算面板打不开且 timeScale=0 卡死。第二次以后因面板已存在、回调同步完成而正常。代码注释自称"协程宿主用常驻 GameRoot"，但实际没改。
2. 🔴 表现层绕过 Command 直接写 Model：`PlayerController.OnTriggerStay2D` 里 `mModel.HP.Value--`（应发 DamagePlayerCommand）。
3. 🟡 文档过期：docs/CODE_WIKI.md 仍写 GameManagerSystem 注册、"3 个全局事件"（实际 4 个），未同步修复报告。
