# 2026-08-30 工作日志

## 代码细节优化（第一轮，小范围、非重构）

对 Game / Gameplay 层做了一轮细节修复与优化，全部保持 QF 分层不变（表现层只 SendCommand、System 只 SendEvent）。

### 行为修复（真 bug）
- **WaveSystem**：存活时间达标后每帧重复 `SendEvent(GameWinEvent)`（timeScale=0 不影响 Update 调用）→ 胜利音效每帧叠加。加 `mWon` 标志，`ResetRun()` 里重置。
- **Enemy.FlashRed**：每次受击取"当前颜色"当原色，连击时把红色记成原色 → 敌人永久变红。改为 `Awake/Start` 缓存 `mOriginalColor` + `mFlashTimer` 计时恢复（`Time.unscaledDeltaTime`），顺带去掉每次受击 new ActionKit.Sequence 的分配。
- **DamageTextPool.Update**：Root 已销毁时仍 `Push(null)` 回空闲栈 → 污染池，后续飘字永远显示不出来。改为 null 直接弃用、不入池。
- **DropSystem.RollDrop**：第二个循环先调 `EffectiveWeight(entry)` 再判 `entry == null` → 空条目 NRE；第一个循环 `EffectiveWeight` 算了两次。调整顺序并缓存单次结果。
- **PickupItem**：Destroy 延迟到帧末，玩家碰到后磁铁同帧 `FindObjectsByType` 仍扫得到 → 奖励重复结算。加 `mCollected` 同帧去重。
- **DamagePlayerCommand**：HP 无下限保护 → `Mathf.Max(0, HP - 1)`。

### 性能 / GC 细节
- PierceSword：命中音效从穿透循环内移出，一次挥砍只播一次（防叠音爆音）。
- AbilitySystem.RollOptions：复用 `mResult` List，空池返回共享的 `sEmptyOptions`。
- DamageTextPool：`GetComponentInChildren<TMP>` 改创建时缓存（DamageText 持有 Root+Tmp）。
- Enemy：玩家引用改静态缓存 `sPlayer`，省掉每个敌人出生一次的 FindWithTag。
- Magnet：`FindObjectsOfType` → `FindObjectsByType(FindObjectsSortMode.None)`。
- PlayerController：`SelfRigidbody2D.transform.localScale` → `transform.localScale`。
- GameRoot：删掉空的 Awake/OnEnable/OnDestroy 与大段注释掉的 OnSceneLoaded（git 有历史，可回溯）。

### 踩坑
- AbilitySystem 里加 `using System;` 会触发 `CS0104: 'Random' is an ambiguous reference`（UnityEngine.Random vs System.Random）。**此项目凡是同时用 UnityEngine.Random 的文件，都不要引 using System**（改用静态空数组等替代 Array.Empty/typeof）。
