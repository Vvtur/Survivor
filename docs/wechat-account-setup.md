# 微信小游戏账号 & 快适配开通 SOP（M0.1 前置）

> 用途：在跑「Unity 微信 SDK 转换导出」之前，必须先完成账号侧三件事：①注册小程序账号 ②拿 AppID ③开通快适配。
> 本 SOP 面向**个人开发者 / 面试作品**，只覆盖"能开发 + 能预览 + 能演示"，不含正式上架资质。
> 界面文案可能随微信后台版本微调，找不到入口时直接搜关键词。

## 0. 前置认知（先看，避免走弯路）
- **小游戏 = 小程序的「游戏」类目**，所以注册体系是「小程序」，AppID 通用，没有独立的小游戏注册入口。
- **顺序不可逆**：注册账号 → 拿 AppID → 开通快适配 → 才能用 Unity 微信 SDK 转换导出。
- **面试作品用「个人」主体即可**：能开发、能预览、能演示；不能开通微信支付 / 虚拟物品交易。
  - 你设计的「分享给好友得服装」走本地存档或云开发即可，不涉支付，个人主体可行。
- **正式上架资质（软著 / 版号 / ICP 等）是 M4 提审阶段的事，现在不用管**，别被这个卡住开发。

## 1. 注册微信小程序账号
[动作]
1. 浏览器打开 `https://mp.weixin.qq.com/`
2. 右上角「立即注册」
3. 账号类型选 **「小程序」**（不是公众号、不是服务号）
4. 填：邮箱（建议新邮箱，未绑定过微信）+ 密码 → 勾协议 → 注册
5. 去注册邮箱点「激活」链接
6. 回来选「主体类型」：
   - **个人**：填姓名、身份证号、手机号 → 微信扫码实名验证
   - 企业：填营业执照、对公账户等（面试作品无需）
7. 提交完成 → 自动登录小程序后台

[验收] 能登录 `mp.weixin.qq.com` 后台，看到小程序管理界面。

## 2. 拿到 AppID
[动作]
1. 登录后台 → 左侧「**开发**」→「**开发管理**」→「**开发设置**」
2. 页面顶部「**AppID(小程序ID)**」即为你的 AppID，形如 `wx1234567890abcdef`
3. 复制保存（后面 Unity 转换、开发者工具导入都要用）

[验收] 拿到 `wx` 开头的 AppID 字符串。

## 3. 开通「快适配」
> ⚠️ 微信后台界面随版本迭代频繁变化。以下路径基于 **2024~2026 新版后台**（左侧导航为：首页/管理/统计/功能/成长/开发支持）实测确认。

[动作]
1. 后台左侧导航找到「**功能**」（带 `>` 箭头的那一项）→ 点进去展开子菜单
2. 子菜单里找「**能力地图**」或「**生产提效包**」→ 点击
3. 在能力列表里找到「**快适配**」（描述含 Unity / 团结引擎 / 快适配等关键词）
4. → 点「**开通**」并按提示确认

[备选路径] 若上述找不到：
- 左侧「**开发支持**」→ 展开看是否有「快适配」或相关入口
- 或在后台顶部/全局搜索框搜「**快适配**」或「**unity**」

[验收] 「快适配」状态变为「已开通」。此时 Unity 里的微信 SDK 转换菜单才能真正生效。

[若完全找不到]
- 可能原因：该小程序主体类型不支持、或该能力尚未对所有账号开放。
- 替代方案：先用「测试号」跑通 R7 验证（见 §4），不影响开发；正式发布前再处理。

## 4. 开发阶段替代：测试号（可选）
- 微信开发者工具登录后，可点「**测试号**」生成一个临时 AppID，能编译预览，但**不能真上架**。
- 用途：若你暂不想注册账号，可先用测试号跑通「转换 → 预览」验证 R7；但正式流程仍建议真实 AppID + 快适配。

## 5. 个人主体注意事项
- 个人小游戏：可开发、可预览、可演示；**不能**开通微信支付、虚拟物品交易。
- 「分享得服装」走本地存档 / 云开发即可，不涉支付，个人主体可行。
- 正式上架需游戏类目资质（软著 / 版号 / ICP 等），属 M4 提审阶段，现在不阻塞。
- 部分游戏子类目个人主体可能受限 → 开发阶段不影响，上架时再处理。

## 6. 常见卡点
- 找不到「快适配」入口 → 确认用 2024+ 新版后台，或后台内搜「快适配」。
- 注册提示邮箱已占用 → 换一个未绑过微信的邮箱。
- 个人主体选不了某些游戏子类目 → 开发阶段不影响，上架时再处理。
- 担心资质问题 → 开发 / 预览 / 演示全程不需要，放心得很。

## 8. 场景：已有公司/他人账号绑定，如何注册"属于自己"的新小程序
> 典型情况：扫码登录 mp.weixin.qq.com 后看到的是以前公司绑的游戏小程序，以为"只能有这一个账号"。

[动作]
1. **不要动公司那个账号的任何设置**（那是公司的，改了有风险）。
2. 在登录后的界面点「退出」，回到 `mp.weixin.qq.com` 首页 / 登录页。
3. 首页右上角「**立即注册**」→ 选「小程序」（这是注册"新账号"，不是"切换"）。
4. **关键：用一个全新的邮箱**（全局唯一，不能与任何已注册公众号/小程序重复；公司那个游戏用的是另一邮箱，所以你用自己的新邮箱即可）。
5. 邮箱激活 → 回来填信息。
6. 主体类型选「**个人**」→ 填**你自己的身份证 + 手机号** → 扫码时**仍用你这个微信**做管理员实名验证。
7. 提交完成 → 新小程序独立生成，拥有自己的 AppID。

[验收] 后台出现一个全新的、与你公司游戏**不同的**小程序账号（各自 AppID 不同）；公司那个原封不动。

[认知澄清]
- 一个微信号可以同时是**多个**小程序的管理员。新小程序和旧公司游戏只是"都挂在你微信这把钥匙下"，彼此是**完全独立的账号**——不同 AppID、不同后台、互不干扰。
- 你做面试作品只用自己的那个 AppID，公司账号千万别碰。
- 个人主体 / 管理员绑定有数量上限（同一身份可注册有限个，具体以微信当前规则为准）。若扫码提示"已达绑定上限"，需解绑不用的账号，或换一个微信做新小程序的管理员。
- 若不想现在注册、只想先验证 R7 → 直接用「微信开发者工具 → 测试号」绕开账号（见 §4），后面确定要长期做再注册。

## 7. 完成后衔接
- 把 AppID 记到 `docs/engine-reference/unity/VERSION.md` 对应处。
- 回到《开发执行手册》M0.1 第 6~8 步：Unity 微信菜单触发转换 → 开发者工具导入（填同一 AppID）→ 预览跑通 → R7 解除。
